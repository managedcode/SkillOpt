# SkillOpt package

Owns typed public optimization contracts, the complete embedded text-space optimization loop, prompt resources, exact patch application, held-out gates, and split reporting. Uses caller-supplied Microsoft `IChatClient` and `IEvaluator`. Keep pure helpers separate from orchestration. Verify with `dotnet build ../../ManagedCode.SkillOpt.sln --configuration Release` and `dotnet test ../../ManagedCode.SkillOpt.sln --configuration Release`.
